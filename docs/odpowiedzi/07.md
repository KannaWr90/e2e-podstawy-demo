## Poprawki

- **01:** dokładna nazwa `{ name: 'Szampon nawilżający', exact: true }`. Zła poprawka: `.first()`. Test przejdzie, ale sprawdzi pierwszy pasujący element, czyli „Szampon dla dzieci”.
- **02:** nazwa przycisku `'Zaloguj'`, przepisana ze strony (UI mode, zakładka „Locator”, albo Codegen). Zła poprawka: większy `timeout`. Test będzie padał dłużej.
- **03:** asercja web-first `await expect(page.getByTestId('order-row').first()).toBeVisible()`, która czeka do 5 s. Złe poprawki: `page.waitForTimeout(2000)` (wolno i nadal niestabilnie, opóźnienie bywa bliskie 2 s) i `isVisible()` (też nie czeka).

Sprawdzenie:
```powershell
npx playwright test --project=zepsute
npx playwright test --project=zepsute tests/zepsute/03-lista-zamowien.spec.ts --repeat-each=10
```
Oczekiwany wynik: `3 passed`, potem `10 passed`.
