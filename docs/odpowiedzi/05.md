## 02-moje-zamowienia.spec.ts

| | |

## Uwaga o `--repeat-each`

Testy 01, 03 i 05 w poprawionej wersji używają jednego konta `user`, testy 07 i 08 konta `tester09`. Kilka kopii tego samego testu uruchomionych równolegle (`--repeat-each=3`) przeszkadza sobie w koszyku i adresach. Powtórki uruchamiaj z `--workers=1`:
```powershell
npx playwright test tests/review --repeat-each=3 --workers=1
```
Oczekiwany wynik: `33 passed`.
